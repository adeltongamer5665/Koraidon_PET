# Koraidon_PET
------Uma aplicação de uma PET de computador, do Pokémon Koraidon------

TEXTO FEITO COM BASE NO 0.0.1 (idealização)
Essa aplicação foi pensada com um modo de ter um pet do Pokémon chamado Koraidon,
ele fica dentro de um espaço retangular que é o seu quartinho, contendo cama, fundo de parede
você pode tocar nele para ver um reação dele, aonde essa reação só acontece em um intervalo de 1s de quando 
você tocou nele, ele pode pairar pela tela em locais aleatórios, e tem tempos e chances dele se mover ou virar pra trás,

Upgrades futuros:

-Summonar comidas com o clique do butão direito do mouse

-local exato de clique para chama a atenção do Koraidon ao invés de clicar na tela dele

-Local para tomar água.

-E possiveis interações de itens, com ref ao jogo Pokémon Scarlet
